# 0.3.0 电脑与手机同步验收

日期：2026-11-06。电脑程序与手机 0.3.0 测试 APK 已生成，不能用 0.2.0 旧包测试以下同步项目。手机包在 `.local/apk/ai-motion-0.3.0-test.apk`，安装前后核对应用版本。每项填“通过 / 失败 / 未测”。本表人工验收默认未测；开发自动化验证另见工作台说明。

## 先只用电脑，约 5–10 分钟

| 编号 | 操作 | 期望结果 | 结果 |
| --- | --- | --- | --- |
| W01 | 双击根目录“启动电脑工作台” | 打开首页，不需要登录、手机或服务器 | 未测 |
| W02 | 编辑第一份模板，改变名称、日期、动作、组数和时间，排序后保存 | 今日只显示安排在今天的计划，重新打开程序后计划仍在 | 未测 |
| W03 | 另存副本、删除副本 | 原计划不变；删除不删除训练记录 | 未测 |
| W04 | 设置每组训练 5 秒、休息 2 秒、2 组，模拟运行 | 训练 → 休息 → 下一组 → 结束，不在最后一组后额外休息 | 未测 |
| W05 | 运行中暂停，等待 10 秒后继续 | 暂停时计时与次数不变化；继续不补算等待时间 | 未测 |
| W06 | 提前结束并查看历史，重启程序再看 | 只出现一条本地记录，来源为模拟，热量不估算 | 未测 |
| W07 | 在模拟运行中让电脑休眠，再唤醒 | 已暂停，未把休眠时间算入训练 | 未测 |
| W08 | 导出备份并再次导入 | 记录不重复，计划和已存 AI 复盘可恢复；不含密钥 | 未测 |
| W09 | 使用损坏 / 错误格式 JSON 导入 | 显示错误，已有记录不受影响 | 未测 |
| W10 | 缩小到最小窗口，使用 Tab 切换焦点 | 页面可滚动、输入与按钮可见，焦点清楚 | 未测 |

## 有手机 0.3.0 新包后再做

| 编号 | 操作 | 期望结果 | 结果 |
| --- | --- | --- | --- |
| S01 | 同一 Wi-Fi，电脑开启接收，手机填写配对链接并连接 | 双方显示连接；Android 17 按需请求本地网络权限 | 未测 |
| S02 | 首次拒绝本地网络权限，再从设置允许后重试 | 拒绝时说明原因，不影响手机离线游戏；允许后能连接 | 未测 |
| S03 | 手机开始、命中、暂停、继续、结束模拟游戏 | 电脑约每秒更新统计，显示模拟来源，结束记录只一条 | 未测 |
| S04 | 手机离线完成两轮，重启手机应用后再连接 | 本地记录保留，补传后两条完整记录，不重复累计 | 未测 |
| S05 | 运动中断开 Wi-Fi，稍后恢复 | 手机继续记录；电脑显示数据过期；恢复后补齐最新阶段 | 未测 |
| S06 | 补传途中再断网，反复恢复 | 最终仍是一轮一条记录，不倒退计时 / 次数 | 未测 |
| S07 | 手机切后台、锁屏后返回 | 游戏按既有逻辑暂停，连接恢复，不产生重复计时器 | 未测 |
| S08 | 电脑关闭接收，再开启 | 旧连接与旧链接失效，重新配对后保留旧训练记录 | 未测 |
| S09 | 重启电脑，手机使用旧链接 | 无法继续旧配对；新链接连接后待传记录仍能补齐 | 未测 |
| S10 | 电脑有 VPN / 多块网卡，选择 Wi-Fi 地址；测试访客网络 | 可选择正确地址；不通时记录网络、防火墙信息 | 未测 |
| S11 | 在系统扫码工具打开电脑二维码 | 能打开时进入配对页，仍需点击连接；不支持时手工输入链接 | 未测 |
| S12 | 未配对时，仅在手机上游戏并重开应用 | 数据能保留，不依赖电脑在线，不上传相机画面 | 未测 |
