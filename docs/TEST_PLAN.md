# 测试计划

## 初始化检查

检查 Git 忽略规则覆盖环境变量、签名密钥、依赖、构建产物、原始录像和下载模型；保留源文件和依赖锁文件。检查提交内容和换行规范。

## 后续自动化测试（未运行）

关键点有效性、躯干中心、坐标映射、镜像、平滑、边界限制、目标碰撞、计分、状态机、暂停和重置。当前尚无实现或测试工具链。

## 真机验收（全部未运行）

按开发任务书 T01–T14 执行：启动、权限、预览、姿态、骨骼对齐、镜像方向、丢失追踪、身体控制、单次计分、游戏流程、结果、释放、连续运行与隐私。

补充测试低光、遮挡、半身、过近或过远、摄像头占用、快速移动、暂停恢复、立即重开和推理中退出。

记录设备型号 / 系统、摄像头分辨率、依赖和模型版本、预览 / 推理 FPS、延迟、连续运行 5 分钟表现及可测量的内存 / 发热情况。不能以模拟器或桌面浏览器结果代替手机结果。
