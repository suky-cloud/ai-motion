# P0 实施顺序

## 第一步：建立开源开发基线

- 保留完整开发任务书。
- 配置 Git 忽略规则、跨平台换行和编辑格式。
- 添加 README、MIT 许可证、贡献说明和状态文档。
- 创建 main 分支并提交初始化内容。
- 将初始化提交发布至 GitHub 公开仓库（需可用的 GitHub 登录）。

## 下一检查点：Step 0 技术验证

- [ ] 确认目标手机平台、型号和可连接真机。
- [ ] 检查并准备包管理器、Android SDK / JDK 或 iOS 构建环境。
- [ ] 阅读开发书指定的三个仓库的 README、核心源码、依赖及许可证。
- [ ] 核实当前 VisionCamera 帧 API、Expo Development Build 和原生模型集成路径。
- [ ] 比较原生与 Web 技术验证路线，补齐 ADR 中的版本、依据和限制。
- [ ] 完成最小帧输入 Spike，再建立正式手机应用。

## 后续顺序

1. 真机摄像头预览、权限、暂停和释放。
2. 姿态识别及镜像、旋转、裁剪后的骨骼对齐。
3. 可测试的运动控制纯函数。
4. Motion Catch 游戏及结果页。
5. 真机性能、异常与隐私验收。

每个检查点记录实际结果，不把文档或代码完成等同于真机验收。
