# AI Motion 0.2.0 实机测试清单

2026-11-06 补充：电脑工作台和手机同步的 0.3.0 验收见 [新增测试清单](DESKTOP_TEST_CHECKLIST.md)。本文件保留原包基线；0.2.0 APK 不包含电脑连接与持久历史，不能用于验收新功能。

准备日期：2026-11-05。建议先花 10–15 分钟做第一组，有空再做权限、异常和稳定性测试。每项填“通过 / 失败 / 未测”，没时间做的留为“未测”即可。

**本版本已有：模拟接目标游戏、暂停与结果页、首页保留本次结果、前置摄像头预览、基础会话和错误恢复框架。**

**本版本还没有：真实人体姿态识别、摄像头画面上的真实骨骼、身体控制目标游戏。** 模拟页里的骨骼是合成数据，不能用它判断识别是否准确。

## 测试前

- 测试包：`ai-motion-0.2.0-test.apk`，已构建并验证签名与内置页面代码。内部测试用，支持 arm64 Android 手机；荣耀 Magic7 Pro 属于本次目标设备。
- 安装后在系统“应用信息”确认版本为 0.2.0，避免误测之前的 0.1.0 开发版。
- 测试包目标是内置页面代码，安装后不需要保持 USB 连接或运行电脑开发服务。首次断网启动也列入下方待验收项，不预先视为已通过。
- 若安装失败，记录完整提示发回，先不用卸载旧版。
- Android 附加静态检查尚待补做（工具下载失败）；本轮未安装到手机，下面各项均待你的实际操作确认。
- 本轮结果只保存在这次应用打开期间；强制关闭或重启应用后结果消失是当前预期行为。
- 测相机时穿普通运动服即可，不需要录屏、保存或上传真实摄像头画面。界面类问题可只描述文字、机型和步骤。
