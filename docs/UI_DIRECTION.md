# AI Motion 界面方向

## 0.3.0 电脑工作台

继续应用同一 frontend-design skill，先按训练用途确定布局后实现：左侧固定任务导航，中间计划表 / 练习现场，右侧进度或证据提示；白色工作纸、冷灰底色、蓝色操作、青绿状态，沿用系统中文字体与等宽数字，不下载字体。只让训练现场的姿态示意承担主要视觉记忆，不用相同圆角卡片铺满页面，不加装饰动画、渐变或宣传指标。

```text
导航        今日计划 / 正在训练                  连接状态
            计划动作表 / 训练示意与计时           本周进度 / 当前提示
            开始、暂停、结束                     本地证据与复盘入口
            最近记录
```

空白状态提供创建模板的入口，不预填虚构历史。模拟与实际输入分开，热量无依据时用空值。按钮 / 表单有键盘焦点，页面可滚动并设置最小窗口尺寸。已在真实 Electron 窗口截图核对首页与训练页；用户缩放和实际手机布局仍待验收。

2026-11-05：用户要求页面自然，避免生硬的 AI 模板感。本轮通过 find-skills 核查并阅读了 [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，只应用设计指导，不引入它的代码或第三方图片。

## 设计计划

产品是用身体参与的短时运动互动。主要视觉记忆放在“移动光标接住圆形目标”的练习场，其余部分保持简洁。首页只说明做什么、用多久、如何开始；不加入健康分析、虚构运动数据或宣传口号。

颜色：纸白 #FFFFFF、冷灰底 #F3F6F8、文字深蓝 #20364A、主操作蓝 #285F85、目标珊瑚红 #D94A60、有效输入青绿 #26736C。状态与文本同时表达，不只依赖颜色。字体采用 Android 系统中文与常规 sans-serif，数字使用等宽数字特性；不下载额外字体。

布局以手机竖屏、左对齐为主：

```text
AI Motion                  返回
Motion Catch
30 秒内，左右移动接住目标

剩余时间     得分       命中
┌─────────────────────────┐
│ 模拟体验                │
│                         │
│   光标 ─────── 目标     │
│                         │
└─────────────────────────┘
跟随手指移动 / 输入丢失提示
暂停                     结束
```

模拟模式明确写“模拟体验，未使用摄像头识别”；通过拖动输入产生合成姿态，结果只称“有效输入时长”，不声称检测到真人。模拟轨迹的骨骼仅是调试显示，可隐藏。技术坐标、置信度和追踪模拟开关收纳到“调试信息”，不用占满主界面。

## 建造前复核

去掉现有首页的全大写技术眉题、泛化口号和大块深底荧光强调。避免整页相同圆角卡片；只给练习场、主要操作和结果分组使用适当边界。动画只用于命中后分数反馈，不自动飘动或装饰性闪烁。按钮触摸高度至少 48，禁用状态可见，系统返回与后台暂停有明确行为。

## 本轮验证边界

用户当前无法接入手机。可以进行类型检查、业务自动化测试与 Metro 打包；不把这些结果称为真机布局、可访问性或触控验收通过。下一次手机可用时检查窄屏、大字体、对比度、触控与相机行为。
